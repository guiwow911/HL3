# 半条命 3：重返黑山
### HALF-LIFE 3 : RETURN TO BLACK MESA
一个可以直接在浏览器里玩的 **第一人称 3D 续作**（粉丝自制，Three.js / WebGL 编写）。
全部贴图由代码程序化生成，全部音效由 WebAudio 实时合成 —— **没有任何外部素材，完全离线可玩**。

---

## 一、怎么开始玩

| 方式 | 操作 | 说明 |
|---|---|---|
| **推荐** | 双击 `启动游戏.bat` | 自动开本地服务器（端口 8123）并打开浏览器 |
| 免安装 | 双击 `index.html` | 用 file:// 直接打开，功能完全一致（无需 Node.js） |
| 手动 | `node server.js` 后访问 `http://127.0.0.1:8123/` | 自己控制端口 |
| 手机玩 | 双击 `启动游戏.bat`，手机打开服务器窗口里列出的局域网地址 | 需同一个 Wi-Fi，手机端自动切触屏操作 |
| **分享给别人** | 双击 **`部署到公网.bat`** | 可选「临时公网隧道（立刻可玩）」或「GitHub Pages（永久地址）」，详见 `部署到公网.md` |

进入页面后点击 **「开始游戏」**，浏览器会请求**锁定鼠标**（第一人称视角必需），请点「允许」。

> 第一次进游戏请先看一眼右下角操作提示。**隧道区域非常黑，按 `F` 开手电。**

**8 把武器**（1~8 顺序，全部有独立模型、双手、可动部件与检视动画）

| # | 武器 | 伤害 | 弹匣 | 特点 |
|---|---|---|---|---|
| 1 | 撬棍 | 58 | — | 近战，挥击动画 |
| 2 | 9mm 手枪 | 17 | 18 | 套筒后坐 |
| 3 | MP7 冲锋枪 | 9 | 45 | 全自动，快 |
| 4 | SPAS-12 霰弹枪 | 9×8 | 6 | 一发 8 颗弹丸，**开火后泵动** |
| 5 | **.357 马格南** | 48 | 6 | 一枪一个杂兵，**转轮会转** |
| 6 | **十字弩** | 100 | 1 | **可穿透 3 个目标**（一字排开一箭三雕） |
| 7 | **AR2 脉冲步枪** | 12 | 30 | 全自动；**右键发射能量球**（34 直伤 + 95 溅射，引爆油桶） |
| 8 | **重力枪** | — | — | **右键抓取（木箱 / 油桶 / 实验台 / 尸体 / 掉落物）→ 左键投掷**（速度越快伤害越高，最高 150）；空手左键是冲击波，可推飞道具、吹开尸体、掀翻敌人 |

> 玩法推荐：**爆炸桶**砸敌群（会连锁引爆）、**尸体**当炮弹、**医疗包**隔空吸取、**实验台**掀翻当掩体。

**战斗要点**
- **爆头 3 倍伤害** —— 打中头部会有提示音。
- **红色油桶会爆炸**，一枪一个，连锁引爆可以清场（也会炸到自己）；被重力枪扔出去撞到东西也会炸。
- **猎头蟹**会跳跃飞扑，行动很快，用霰弹枪最省事；**站在箱子/高台上它咬不到你**。
- **僵尸**死后有几率从尸体里爬出两只猎头蟹。
- **联合军士兵**会保持中距离点射、横向走位，优先躲掩体再对射。
- **护甲（SUIT POWER）** 会替你挡掉一半伤害，别忘了捡电池。
- **枪声会引来敌人**（难度越高传得越远），所以能省则省。

## 二·五、手机 / 平板游玩

**1. 让手机能访问**
双击 `启动游戏.bat`，在弹出的服务器窗口里会看到形如 `http://192.168.x.x:8123/` 的地址（服务器已监听 `0.0.0.0`，不是只有本机能访问）。
确保**手机和电脑连的是同一个 Wi-Fi**，然后用手机浏览器打开那个地址。

**2. 手机端会自动切换为触屏操作**

| 操作 | 说明 |
|---|---|
| **左下虚拟摇杆** | 移动；推到底自动疾跑 |
| **屏幕任意处拖动** | 转动视角（不用点准某个区域，除了按钮以外全屏都能拖） |
| **开火**（右下大圆键） | 按住连发 / 单发射击 |
| **副** | 鼠标右键功能：AR2 能量球 · 重力枪抓取/放下 |
| **跳 / 蹲 / 弹 / 雷 / 用** | 跳跃 · 蹲下（**点一下切换**，不用一直按）· 装弹 · 手雷 · 交互（长按关阀门） |
| **◀ ▶**（右上） | 切换武器 |
| **检视 / 灯 / ‖** | 检视动画 · 手电 · 暂停 |

**3. 移动端专属优化**

| 项目 | 桌面端 | 移动端 |
|---|---|---|
| 抗锯齿 | 开 | 关（省大量填充率） |
| 渲染分辨率倍率 | 1.5 | 1.0 |
| 灯光池 | 8 盏 | **5 盏**（逐像素光照开销直接下降） |
| 默认画质 | 高（含泛光后期） | 低（关闭后期处理） |
| **瞄准辅助** | 无 | **命中体积 ×1.45**（触屏瞄准不精确，实测偏离中心 3.4° 仍能命中） |
| HUD 布局 | 常规 | 精简重排（血量移到左上、弹药右上、武器栏顶部、字幕上移），按钮避开摇杆区域 |
| 全屏 | — | 点击「开始游戏」时自动请求全屏 + 尝试锁定横屏 |
| 竖屏提示 | — | 竖屏时全屏提示「请横屏游玩」 |

**想在电脑上试触屏操作**：用 `index.html?mobile=1` 打开即可（强制触屏模式）；反之 `?pc=1` 可强制桌面模式。

## 二·六、自动识别手机 / 电脑

打开页面时会**自动判断**你用的是手机还是电脑，并切换操作方式与画质档位。识别在页面加载前完成（写在 `<head>` 里的内联脚本），结果会显示在主菜单「操作方式」那一行的说明文字里。

**识别依据（按优先级，命中即停）**

| 顺序 | 信号 | 说明 |
|---|---|---|
| 1 | `navigator.userAgentData.mobile` | Chromium 官方字段，最可靠 |
| 2 | **iPadOS 伪装成 Mac** | iPadOS 13+ 的 `platform` 是 `MacIntel`，用 `maxTouchPoints > 1` 识别 |
| 3 | UA 关键字 | Android / iPhone / iPad / 平板 / Kindle 等 |
| 4 | `pointer: coarse` + `hover: none` + 有触摸 | 主输入是手指、且没有悬停能力 |
| 5 | 有触摸 + **完全没有精确指针** + 屏幕短边 < 900 | 兜底 |

> 第 5 条里的「完全没有精确指针(`any-pointer: fine` 为假)」很关键：**否则带触摸屏的笔记本会被误判成手机**。

**实测识别矩阵**（用真实 UA 跑过）

| 设备 | 结果 |
|---|---|
| 桌面 Chrome 1366×768 / 900×500 | 电脑端 ✔ |
| Windows 触摸笔记本 | 电脑端 ✔（有鼠标就不抢触屏操作） |
| iPhone / Android 手机 | 移动端 ✔ |
| **iPad 1024×1366（大屏平板）** | 移动端 ✔ |
| **Android 平板 1280×800** | 移动端 ✔ |
| iPadOS 13+（Macintosh UA + 5 触点） | 移动端 ✔ |
| Windows 触摸笔记本（仅触摸） | 移动端 ✔ |

**识别错了怎么办**：主菜单「操作方式」可随时手动切换（**自动识别 / 触屏 / 键盘鼠标**），切换**立即生效**，不需要重开游戏，并会记忆在浏览器里（localStorage）。下拉框里「自动识别（触屏/键鼠）」会直接显示当前识别结果。

也可以用 URL 参数强制：`index.html?mobile=1`（强制触屏）、`?pc=1`（强制键鼠）。

## 三、难度（默认「困难」）

主菜单里可选，切换后**重新开始生效**（HUD 右上角会显示当前难度）：

| 难度 | 敌人血量 | 敌人伤害 | 敌人速度 | 刷怪数量 | 护甲吸收 | 补给 | 其他 |
|---|---|---|---|---|---|---|---|
| 简单 | ×0.8 | ×0.7 | ×0.9 | ×0.75 | 60% | ×1.35 | 枪声传播近 |
| 普通 | ×1.0 | ×1.0 | ×1.0 | ×1.0 | 50% | ×1.0 | — |
| **困难**（默认） | **×1.3** | **×1.45** | **×1.12** | **×1.35** | **36%** | **×0.8** | **Boss 残血狂暴 · 枪声传 22m** |
| 噩梦 | ×1.7 | ×1.9 | ×1.25 | ×1.7 | 25% | ×0.62 | Boss 狂暴 · 枪声传 28m |

**困难以上的额外压力**
- **枪声会惊动附近敌人**：隔墙蹲着的僵尸也会被枪声吸引过来（简单档传播距离很短，可以放心开枪）。
- **爆炸传播更远**（36m），用油桶清场会引来更多敌人。
- **充能站次数 3 → 2**（补血补甲的机会变少）。
- **Boss 狂暴**：血量低于 42% 后移速 +35%、冲撞更频繁、攻击范围更大。
- 僵尸死亡后爬出猎头蟹的概率与数量提升。

**实测数值（困难）**：僵尸 124 血 / 单次近战 25；猎头蟹 36 血 / 单次撕咬 13；联合军 101 血；蚁狮守卫 1625 血。
**噩梦**：僵尸 162 血 / 单次近战 32（四口咬死满血无甲的你）。

## 四、猎头蟹攻击判定

判定全部按**真实体积 + 正锥**计算，不再隔空咬人：

| 情况 | 结果 |
|---|---|
| 扑击途中**身体接触**到你 | 立刻撕咬（招牌攻击） |
| 落地后贴身 ≤1.2m | 0.16s 前摇 → 向前一扑 → 命中判定 |
| 距离 1.6m 以上 | **咬不到**（旧版能隔 2.6m 咬到，已修） |
| 你站在 1.6m 高台/箱子上 | **地面上的猎头蟹咬不到**（它只有 0.66m 高） |
| 它跳起来扑到你身上 | 照样咬得到（所以别在台边浪） |
| 背对你时 | 不会咬（正锥判定） |

**站箱子和高台是有效战术** —— 想咬到你就必须先跳上来。

## 五、关卡流程

1. **东翼仓库**（起点）—— 拿手枪，认识撬棍。
2. **通道 A** —— 进入基地内部。
3. **中央中庭** —— 三层空间 + 天桥。头蟹伏击；**从东侧楼梯爬上二层天桥可以拿到 MP7 冲锋枪**。
4. **西侧军械库**（支线，推荐去）—— 霰弹枪 + 弹药，但有联合军把守。
5. **通道 B → 生物实验室** —— 中央是**毒污泥池**（站进去持续掉血），僵尸 + 培养槽，从东侧门离开。
6. **连接通道 → 维护隧道** —— **全黑**，手电必备，头顶会掉猎头蟹。
7. **通道 C → 反应堆核心** —— 巨型反应堆柱。**关闭 3 个冷却阀门（长按 E）**。
8. **决战** —— 阀门全部关闭后，**蚁狮守卫**（Boss，1250 HP）带着联合军和头蟹冲出来。
9. **逃离** —— 干掉蚁狮守卫，北墙的**传送门**激活，走进去即可通关（会结算击杀数/用时/命中率）。

## 七、技术实现（想改造可以看这里）

- **程序化贴图**：混凝土 / 瓷砖 / 金属 / 锈蚀 / 木箱 / 警示条纹 / 通风栅格 /
  毒性污泥 / 玻璃 / 灯板 / 传送门 / 弹孔，全部用 `Canvas 2D` 现场绘制成贴图，
  再按物体尺寸设置 UV 重复。**改颜色只要改 `core.js` 里的 `GEN` 函数**。
- **音频合成**：`G.audio` 里用振荡器 + 白噪声 + 滤波器实时合成 30 多种音效
  （枪声、猎头蟹尖叫、僵尸呻吟、爆炸、联合军无线电……），还有一条持续的环境低鸣。
- **碰撞**：全部实体都是 AABB，`G.moveBody()` 做分轴解算 + **台阶辅助**
  （所以能自然走上楼梯和箱子），`G.rayWorld()` 用平板法做射线求交，
  子弹用**解析式射线 vs AABB / 球体**命中判定（比三角面检测快且可控）。
- **敌人 AI**：视线遮挡检测 + 状态机（待机 / 追击 / 攻击 / 死亡），
  按类型区分：跳跃突进（猎头蟹）、直线逼近 + 死亡召唤（僵尸）、
  距离维持 + 点射（士兵）、蓄力冲撞 + 震地（蚁狮守卫）。被墙卡住会自动侧向绕行。
- **性能**：灯光按玩家所在房间动态裁剪；特效全部走对象池；
  武器用独立场景二次渲染，避免贴墙穿模。
- **暂停安全**：所有延时结算（近战判定、Boss 震地）都走游戏内计时器队列，
  暂停时不会偷跑伤害。

## 八、常见问题

**黑屏 / 一直显示“正在构建黑山基地”**
说明浏览器不支持 WebGL。请用较新的 Chrome / Edge / Firefox，并在设置里开启硬件加速。

**鼠标不能转视角**
必须点击页面内的「开始游戏」按钮（浏览器规定：锁定鼠标必须由用户操作触发）。
如果点了没反应，检查地址栏右侧是否有被拦截的权限图标。

**没有声音**
浏览器规定音频必须由用户操作后启动 —— 点一下「开始游戏」或动一下音量滑块即可。

**手电按了没亮**
手电有电量，用久了会耗尽；HUD 右上角会显示剩余百分比。

**帧数偏低**
在显卡驱动里开启硬件加速；或把浏览器窗口调小。场景里有几十盏动态光源，
均做了距离裁剪，正常情况下桌面独显/核显都能跑满 60 帧。

## 九、修复与更新记录

### 版本 1.9 —— 自动识别手机 / 电脑
| 内容 | 说明 |
|---|---|
